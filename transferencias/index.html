1Existencias de las granjas

Las granjas vienen en el reporte que se baja en Conteo de stock, con la fecha "hasta" que elegiste ahí (por defecto un mes adelante: incluye los movimientos con fecha futura). Las oficinas no se egresan nunca.

Egresos y campaña

Bajar existencias solas (en esta compu)

A esa hora se abre Transferencias en una pestaña y baja las existencias de Albor, como si tocaras el botón; quedan guardadas en esta compu para todo el día. Si Albor pide ingresar, toca INGRESAR solo (Chrome tiene que tener guardada la contraseña). Chrome tiene que estar abierto: si estaba cerrado a esa hora, lo hace al abrirlo. Se elige en cada compu.

Catálogo (lo que ven los encargados en Armar pedido)

Sale de las existencias cargadas, sin los productos excluidos. Publicalo de nuevo cuando aparezcan insumos nuevos en Albor.

Envíos posibles

Una línea por comprobante, con los datos separados por punto y coma:
nombre ; empresa ; id origen ; nombre origen ; id destino ; nombre destino
Dos líneas con el mismo nombre salen como control doble. Un ? quiere decir que ese dato lo elegís a mano en Albor. El nombre del origen tiene que estar escrito igual que en el CSV de existencias.

Granjas

Una línea por granja: nombre del punto ; empresa ; id del punto ; centro de costo
El nombre del punto tiene que estar escrito igual que en el CSV de existencias. Los números los ves con "Traer de Albor", arriba (o usá "Agregar una granja").

Tipos de insumo y su cuenta contable

Una línea por tipo: TIPO DE INSUMO ; cuenta. El tipo que no esté en esta lista no se egresa — así quedan afuera el alimento y las premezclas.
Para un producto que no siga la regla de su tipo: cod: VAC0033738 ; 510201003

Productos excluidos del conteo

Una regla por línea: un código de insumo para sacar un producto suelto, o cat: NOMBRE para sacar una categoría entera. Lo que va después de un # es solo una nota. Un código que no exista en el CSV se ignora.
